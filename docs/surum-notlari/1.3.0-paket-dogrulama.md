# 1.3.0+10 — paket doğrulama kaydı

Aşağıdakilerin hepsi **üretilen paketin içinden** okundu; kaynak
koddan değil.

## Sürüm

| | değer | nereden |
|---|---|---|
| versionName | `1.3.0` | `aapt2 dump badging` (APK) |
| versionCode | **`10`** | aynı |
| paket kimliği | `com.app.yonetiyor` | aynı |
| targetSdkVersion | **`36`** | aynı |
| minSdkVersion | `24` | aynı |
| compileSdkVersion | `36` | aynı |

**Neden 10:** Play'de ve App Store'da 9 kullanıldı; yeni numara ikisinden
de büyük olmalı. `1.2.2 → 1.3.0`: bu turda kullanıcıya görünen yeni
yetenekler var (görünüm modu, arama, görev takibi, çok gruplu vardiya,
güvenlik amiri rolü), yama değil.

**targetSdk 36** Android'in en güncel API seviyesi (Android 16); Play'in
"son sürümden geri kalmama" şartını karşılıyor.

## Gömülü adres

`lib/arm64-v8a/libapp.so` içinden çıkarılan http(s) adresleri:

```
https://api.yonetio.site      ← bizim yapılandırdığımız
https://api.flutter.dev       ┐
https://developer.mozilla.org │ Flutter/Dart kütüphanelerinin
https://docs.flutter.dev      │ belge bağlantıları
https://firebase.google.com   │
https://github.com            │
https://pub.dev               ┘
```

Emülatör/yerel adres araması — **hiçbiri yok**:
`10.0.2.2`, `127.0.0.1`, `192.168.`, `test.yonetio`, `app-test`.

**`localhost` hakkında — ilk okumada yanlış alarm verdim.** Dizge pakette
**bir kez** geçiyor ve komşuları Dart kütüphane dizgeleri ("Too many
percent/permill", "get:isEven"). URL biçiminde (`http://localhost:…`)
**geçmiyor** ve mobil kaynak kodunda `localhost` hiç yok. Yani bizim
yapılandırdığımız bir adres değil, Dart SDK'sının kendi dizge havuzu.

## Bildirim sesleri

`resources.arsc` içinde üç kaynak adı da var: `yonetio_bildirim`,
`yonetio_gurultu`, `yonetio_vardiya`. Dosyalar pakette `res/KX.ogg`,
`res/Od.ogg`, `res/cV.ogg` olarak duruyor — **ada göre aramak yanlış
olurdu**, yayın yapımında dosya adları kısaltılıyor; Android kanalı sesi
kaynak adıyla çözer.

## İkon

`ic_launcher` kaynak tablosunda var; ikon kaynağı paketten yeni değil
(yapım bayat değil). **Piksel içeriği doğrulanmadı** — yayın yapımında
PNG'ler yeniden sıkıştırılıyor, bayt özeti asla tutmaz. İkonun görsel
olarak doğru olduğu gözle doğrulanmalı.

## Dukkan sekmesi

Paket bu bayrağı **gömmüyor**, sunucuya soruyor. Zincir baştan sona
kapalı:

* `backend/app/config.py:474` → `dukkan_mobil_acik: bool = False`
* `GET /ozellikler` bu değeri döndürüyor
* `dukkanAcikProvider` (mobil) üç yolda da kapalı: yüklenirken `false`,
  **hata halinde `false`**, değer yoksa `false`

Sunucu bayrağı açılmadıkça bu paket "yakında" gösterir — ve açmak için
yeni paket gerekmez.
