## 5. iOS — Mac'te senin yapacakların

`.ipa` bu makinede üretilemez; `docs/app-store/ios-build-runbook.md` ile
birlikte oku.

1. `git pull` yap; kod `3be28242` ya da sonrası olmalı.
2. `cd mobile && flutter clean && flutter pub get && cd ios && pod install`.
   Yeni eklenti `record` iOS pod'u getiriyor.
3. **Xcode → Runner → Signing & Capabilities → + Time Sensitive
   Notifications.** Yetki dosyası bu yeteneği artık istiyor. App ID'de açık
   değilse ve profil onu taşımıyorsa **imza başarısız olur**. Otomatik
   imzada Xcode profili kendiliğinden günceller.
4. **Critical Alerts'i EKLEME.** Apple onayı bekleniyor (A5HC6338GM).
   Onaysız eklenirse imza kırılır.
5. Derleme:
   ```bash
   flutter build ipa --release \
     --dart-define=API_BASE_URL=https://api.yonetio.site \
     --dart-define=WEB_BASE_URL=https://yonetiyor.com
   ```
6. TestFlight'ta **18** numarası daha önce kullanıldıysa build numarasını
   artır (runbook §2.5).
7. **Product → Archive → Distribute → Upload.**

### 5.1 `AppDelegate.swift` — derlenmemiş yeni kodun olası hata noktaları

P249 §1'de eklenen `kurAlarmKanali` bu makinede derlenmedi. En olasıdan
başlayarak:

1. **`ayar.criticalAlertSetting`** (iOS 12+) ve
   **`ayar.timeSensitiveSetting`** (iOS 15+) `#available` korumasında.
   Deployment target 13.0 olduğu için iOS 12 koruması gereksiz ama
   zararsız; derleyici uyarı verebilir.
2. **`getDeliveredNotifications` kapanışı** arka plan kuyruğunda çalışır.
   `sonuc(nil)` bu yüzden `DispatchQueue.main.async` içinde çağrılıyor.
   Unutulsaydı Flutter "result must be called on main thread" diye
   çökerdi.
3. **`$0.request.content.userInfo["panik_id"] as? String`**: FCM `data`
   anahtarlarını APNs yükünün üst düzeyine koyar. Anahtar yoksa susturma
   hiçbir bildirimi kaldırmaz; bu hata değil, etkisizliktir.
4. **`registry.registrar(forPlugin: "YonetioAlarm")`**: mevcut iki kanalla
   aynı desen; anahtar benzersiz.

### 5.2 Cihazda göz kontrolü (bu makinede ÖLÇÜLEMEDİ)

`docs/P249-kararlar.md` "ÖLÇÜLEMEDİ" başlıklarındaki listeler. Kısaca:
- **Android:**
  - uygulama kapalı ve telefon sessizken DEPREM SOS'u gelip alarm sesi
    döngüde çalıyor mu, dokununca alarm ekranı açılıp "Güvendeyim" ile
    ses susuyor mu;
  - Android 14+'da tam ekran için "SOS alarm ayarları" kartındaki izin.
- **iOS:** bildirim Odak modunda geliyor mu; sessizde çalmaz (beklenen).
- **Sesli mesaj:** mikrofon izni penceresi, basılı tutup kayıt, sakin
  telefonunda oynatma.
- **Tatbikat:** iki cihazdan "Güvendeyim" ve web'de rapor/PDF.
